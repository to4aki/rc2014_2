RC2014 HLOAD / USR 忘備録
=========================

■ HLOADとは

Intel HEX形式のプログラムをメモリへロードする。

    HLOAD

実行後に Intel HEX を送信する。

ロード完了後、自動的に USRLOC が設定される。


■ USRLOC

場所

    8203h : JP xxxx
    8204h : xxxx (LSB)
    8205h : xxxx (MSB)

例

    :059000003E2AD381C91E

をロードすると

    USRLOC = 9000h

となる。

確認

    PRINT PEEK(&8204)
    PRINT PEEK(&8205)

表示

    0
    144

なら 9000h。


手動設定

    DOKE &8204,&9000


------------------------------------------------------------

■ HLOAD後の機械語実行

    PRINT USR(0)

で実行。

例

    ORG $9000

    LD A,'*'
    OUT ($81),A
    RET

結果

    *
    0


------------------------------------------------------------

■ 割り込み注意

キー入力処理時に

    801C

へ飛ぶ場合がある。

対策

    DI

を入れる。

終了時は

    EI
    RET

を忘れない。


例

EXIT:
    EI
    RET


------------------------------------------------------------

■ USR(x) の引数取得

BASIC

    PRINT USR(1234)

機械語

    CALL $0AE1

DEINT実行後

    DE = 1234

になる。


定義

    DEINT = 0AE1h


------------------------------------------------------------

■ 戻り値返却

戻したい16bit値を

    A = 上位8bit
    B = 下位8bit

へ入れ

    JP $1274

する。

定義

    ABPASS = 1274h


------------------------------------------------------------

■ サンプル１（+1関数）

    ORG $9000

    CALL $0AE1

    INC DE

    LD A,D
    LD B,E

    JP $1274

実行

    PRINT USR(1234)

結果

    1235


------------------------------------------------------------

■ サンプル２（2倍関数）

    ORG $9000

    CALL $0AE1

    SLA E
    RL  D

    LD A,D
    LD B,E

    JP $1274

実行

    PRINT USR(1234)

結果

    2468


------------------------------------------------------------

■ 複数関数を使う方法

方法１（おすすめ）

USRLOCを書き換える。


2倍関数

    DOKE &8204,&9100
    PRINT USR(10)

結果

    20


3倍関数

    DOKE &8204,&9200
    PRINT USR(10)

結果

    30


メリット

- USR(x) の x をそのまま引数として使える
- 関数ID分岐が不要
- 機械語側がシンプル


------------------------------------------------------------

■ 関数ID方式（あまりおすすめしない）

BASIC

    PRINT USR(1)

機械語

    CALL DEINT

    LD A,E

    CP 1
    JP Z,FUNC1

    CP 2
    JP Z,FUNC2

欠点

- 引数を関数番号に消費してしまう


------------------------------------------------------------

■ HLOADが実際にやっていること

ソース

    ld (USR+1),de

USR定義

    USR = 8203h

結果

    8203 C3
    8204 00
    8205 90

↓

    JP 9000h

になる。

つまり HLOAD は

    ロード
      ↓
    USRLOC設定

まで自動でやってくれる。


------------------------------------------------------------

■ よく使うアドレス

USRLOC      8204h
DEINT       0AE1h
ABPASS      1274h


------------------------------------------------------------

■ 開発フロー

hello.asm
  ↓
z80asm
  ↓
hello.bin
  ↓
Intel HEX変換
  ↓
HLOAD
  ↓
PRINT USR(0)

これで BASIC から Z80関数を呼び出せる。
